Q1

WHAT IS THE OUTPUT?

#include <stdio.h>

int main() {
    int i = 1;

    while (i++ <= 3)
        printf("%d ", i);

    return 0;
}
A
1 2 3
B
2 3 4
C
2 3 4 5
D
1 2 3 4

CORRECT ANSWER: B) 2 3 4

The important trick is that i++ is post-increment.

Initially i = 1
Condition checks 1 <= 3 → true, then i becomes 2. Prints 2.
Condition checks 2 <= 3 → true, then i becomes 3. Prints 3.
Condition checks 3 <= 3 → true, then i becomes 4. Prints 4.
Condition checks 4 <= 3 → false.

Therefore: 2 3 4
Q2

WHAT IS THE OUTPUT?

#include <stdio.h>

int main() {
    int i = 0;

    while (i < 5) {
        printf("%d ", i);
        i += 2;
    }

    return 0;
}
A
0 2 4
B
0 2 4 6
C
1 3 5
D
0 1 2 3 4

CORRECT ANSWER: A) 0 2 4

The loop condition is: i < 5

Iteration 1: 0 < 5 (True) → Prints 0, i becomes 2.
Iteration 2: 2 < 5 (True) → Prints 2, i becomes 4.
Iteration 3: 4 < 5 (True) → Prints 4, i becomes 6.
Iteration 4: 6 < 5 (False).

The common mistake is to include 6, but 6 is never printed because the condition fails before the fourth iteration.
Q3

WHAT IS THE OUTPUT?

#include <stdio.h>

int main() {
    int i = 5;

    while (i-- > 2)
        printf("%d ", i);

    return 0;
}
A
5 4 3
B
4 3 2
C
4 3
D
5 4 3 2

CORRECT ANSWER: B) 4 3 2

Again, i-- is post-decrement. The old value is used for comparison, and then i is decreased.

First: 5 > 2 (true) → i becomes 4, prints 4.
Second: 4 > 2 (true) → i becomes 3, prints 3.
Third: 3 > 2 (true) → i becomes 2, prints 2.
Fourth: 2 > 2 (false).

The tricky point is that 2 is printed, even though the condition is > 2. The comparison uses the old value 3.
Q4

WHAT IS THE OUTPUT?

#include <stdio.h>

int main() {
    int i = 1, sum = 0;

    while (i <= 5) {
        if (i % 2 == 0)
            sum += i;
        i++;
    }

    printf("%d", sum);

    return 0;
}
A
6
B
9
C
15
D
10

CORRECT ANSWER: A) 6

The loop processes: 1, 2, 3, 4, 5.

Only even numbers satisfy i % 2 == 0. (i.e., 2 and 4).

So: 2 + 4 = 6.

A common mistake is to calculate the sum of all numbers (15) instead of noticing that only even numbers are added.
Q5

WHAT IS THE OUTPUT?

#include <stdio.h>

int main() {
    int i = 1;

    while (i <= 3) {
        printf("%d ", i);

        if (i == 2)
            i += 2;
        else
            i++;
    }

    return 0;
}
A
1 2 3
B
1 2 4
C
1 2
D
1 3

CORRECT ANSWER: C) 1 2

Iteration 1: 1 <= 3 → true. Prints 1. i is not 2, so i++. Now i = 2.
Iteration 2: 2 <= 3 → true. Prints 2. i == 2 is true, so i += 2. Now i = 4.
Iteration 3: 4 <= 3 is false, so the loop stops.

The trick is that i jumps from 2 directly to 4, skipping 3.

DO - WHILE LOOP MCQs

Q6 to Q10

Q6

WHAT IS THE OUTPUT?

#include <stdio.h>

int main() {
    int i = 5;

    do {
        printf("%d ", i);
        i++;
    } while (i < 5);

    return 0;
}
A
No output
B
5
C
5 6
D
4 5

CORRECT ANSWER: B) 5

The most important property of a do-while loop is that its body executes at least once.

Initially: i = 5.
The body executes first: Prints 5. Then i++ makes i = 6.
Now the condition is checked: 6 < 5 which is false.

Therefore, 5 is printed.
Q7

WHAT IS THE OUTPUT?

#include <stdio.h>

int main() {
    int i = 1;

    do {
        printf("%d ", i);
        i *= 2;
    } while (i <= 8);

    return 0;
}
A
1 2 4 8
B
1 2 4 8 16
C
2 4 8 16
D
1 2 4

CORRECT ANSWER: A) 1 2 4 8

Iteration 1: Prints 1. i *= 2 → 2. (2 <= 8) True.
Iteration 2: Prints 2. i *= 2 → 4. (4 <= 8) True.
Iteration 3: Prints 4. i *= 2 → 8. (8 <= 8) True.
Iteration 4: Prints 8. i *= 2 → 16. (16 <= 8) False.

The tricky part is that 8 is printed. After printing 8, the value becomes 16, and only then does the condition fail.
Q8

WHAT IS THE OUTPUT?

#include <stdio.h>

int main() {
    int i = 3;

    do {
        printf("%d ", i--);
    } while (i > 0);

    return 0;
}
A
3 2 1
B
2 1 0
C
3 2 1 0
D
3 2

CORRECT ANSWER: A) 3 2 1

Here i-- is post-decrement.

Prints 3 → i becomes 2.
Condition (2 > 0) → True.
Prints 2 → i becomes 1.
Condition (1 > 0) → True.
Prints 1 → i becomes 0.
Condition (0 > 0) → False.

Notice that 0 is not printed, because the value becomes 0 only after printing 1.
Q9

WHAT IS THE OUTPUT?

#include <stdio.h>

int main() {
    int i = 10;

    do {
        i -= 3;
        printf("%d ", i);
    } while (i > 5);

    return 0;
}
A
10 7 4
B
7 4
C
7 5
D
10 7 4 1

CORRECT ANSWER: B) 7 4

First iteration: i -= 3 → 7. Prints 7. Condition: 7 > 5 (True).
Second iteration: i -= 3 → 4. Prints 4. Condition: 4 > 5 (False).

Therefore: 7 4.
The key trick is that the subtraction occurs before the printf().
Q10

WHAT IS THE OUTPUT?

#include <stdio.h>

int main() {
    int i = 1;

    do {
        printf("%d ", i);

        if (i % 2 == 0)
            i += 3;
        else
            i += 2;

    } while (i < 10);

    return 0;
}
A
1 3 5 7 9
B
1 3 5 8
C
1 3 6 9
D
1 3 5 7

CORRECT ANSWER: A) 1 3 5 7 9

Since 1 is odd, i += 2 makes i = 3 (Prints 1).
Since 3 is odd, i += 2 makes i = 5 (Prints 3).
Since 5 is odd, i += 2 makes i = 7 (Prints 5).
Since 7 is odd, i += 2 makes i = 9 (Prints 7).
Since 9 is odd, i += 2 makes i = 11 (Prints 9).

Then 11 < 10 is false.
The trap is the if condition: because every printed value is odd, the i += 3 branch is never executed.
